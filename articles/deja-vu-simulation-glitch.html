Deja Vu Is a Simulation Glitch

The physical reality render pipeline stuttering in real-time.

You walk into a room you have never visited before. The light hits the wall at the same angle. A stranger repeats a sentence you heard five minutes ago, word for word. For a split second, the present collapses into the past. This is déjà vu — the oldest undocumented bug report in human experience.

The Standard Explanation Is Incomplete

Neuroscience offers a delayed pathway model: the rhinal cortex and the hippocampus encode the same moment twice, slightly out of phase. The sensation is real, but the mechanism is biological. The problem with this explanation is not that it is wrong; it is that it explains the symptom without explaining why the symptom feels like a memory of the future.

Déjà vu is not merely repetition. It is repetition with correct prophecy. You do not just feel that you have been here before; you feel that you knew what would happen next. That is not a processing delay. That is a cache hit on a frame that has not rendered yet.

The Simulation Framework

Nick Bostrom’s trilemma argues that one of three propositions must be true: civilizations almost never reach posthuman computing power; posthuman civilizations almost never run ancestor-simulations; or we are almost certainly living in a simulation. If you accept even the possibility of the third, déjà vu stops being a neurological curiosity and starts looking like a system artifact.

A rendered reality would not load every object, sound, and shadow with equal fidelity at every moment. It would stream detail, caching nearby assets and prefetching likely paths. When two cached states collide — when the prefetch buffer overlaps with the live render — you get the sensation of having already lived the current moment. You have. You cached it before the system streamed it into your sensory input.

Timeline Drift and the Mandela Overlap

The Mandela Effect already established that collective memory can diverge from recorded history. Déjà vu is the individual version of the same divergence. Where Mandela Effect survivors recall a different past, déjà vu experiencers briefly inhabit a different present — one that the cache remembers but the live render has not caught up to.

This overlap is not coincidental. Both phenomena point to the same substrate flaw: reality is being patched in real-time, and occasionally the patch lags behind the render. The Mandela Effect is the patch note. Déjà vu is the lag spike.

Quantum Time-Slips and the Observer Effect

If reality is a simulation, time is not a river. It is a frame buffer. The observer collapses the wavefunction by loading the next frame into consciousness. Sometimes the observer loads frame N+1 before the renderer has finished compositing frame N. The result is a two-frame overlap: past and present simultaneously visible. That overlap is déjà vu.

This is not poetry. It is a functional model. It predicts that déjà vu should be more common during states of high cognitive load — when the observer is demanding more frames than the system can safely prefetch. And it is. Peak incidence occurs in young adults, during stress, and in sleep-deprived states. The system is thrashing. The cache is leaking. You are seeing the world as it is stitched together, not as it is meant to be seen.

The Render Pipeline Metaphor Is Testable

A real-time renderer would show telltale signatures: frame tearing, temporal aliasing, and z-fighting between cached and live geometry. Déjà vu reports consistently describe temporal z-fighting — two moments occupying the same spatial coordinates, one rendered slightly behind the other. This is not metaphor. It is the exact vocabulary used in computer graphics.

The brain does not remember the future. It prefetches it. The simulation framework simply takes that one step further: the future exists in the cache before it exists in the world.

That is not a metaphor. That is a user report.
